OpenAI / Realtime API / Voice AI

GPT‑Realtime‑2など音声AI 3モデルをAPIに追加。音声エージェントが重要テーマへ

30秒概要

OpenAIは2026年5月7日、Realtime API向けにGPT‑Realtime‑2（GPT‑5級推論の音声モデル）、GPT‑Realtime‑Translate（70+入力→13出力の同時翻訳）、GPT‑Realtime‑Whisper（ストリーミング文字起こし）を発表。音声UIを「話すだけ」から「推論し、ツールを使い、作業を進める」方向へ押し上げる更新で、価格・コンテキスト拡大・推論レベル調整まで一気に整備された。

本文要約

OpenAI公式発表では、Realtime APIに新世代の音声モデルを3つ追加したと説明しています。狙いは、低遅延の「音声入力→音声出力」だけでなく、会話中に推論し、翻訳し、文字起こしし、必要に応じてツールを呼び出して作業を進める音声エージェントの実装を現実的にすることです。

中心となるGPT‑Realtime‑2は、OpenAIが「GPT‑5‑class reasoning」を備えた初の音声モデルと位置づけています。会話の流れを保ったまま、ツール呼び出し、割り込みや訂正からの回復、適切なトーン調整までを含めた“実運用の会話”を想定した仕様で、コンテキスト長も32K→128Kへ拡大するとしています。さらに、開発者側で推論レベル（minimal〜xhigh）を選べるようにし、遅延と深さのトレードオフを制御できる設計になっています。

GPT‑Realtime‑Translateは、70以上の入力言語から13の出力言語へ、話者の速度に追従しながら翻訳するモデルとして紹介されています。音声対応のカスタマーサポート、イベント、多言語会議、教育などで「人が話している最中に翻訳と文字起こしが並走する」体験をアプリに組み込めることが主眼です。GPT‑Realtime‑Whisperは低遅延のストリーミング文字起こし（字幕、議事録、ライブ要約など）に焦点を当てています。

価格も明示されました。GPT‑Realtime‑2は音声入力$32/1M audio input tokens（cachedは$0.40/1M）・音声出力$64/1M audio output tokens。Translateは$0.034/分、Whisperは$0.017/分です。実装の初期段階からコスト試算できる点は、プロダクト計画上の重要材料です。

TechCrunchも、開発者が音声対話・翻訳・文字起こしアプリを作りやすくする更新として報じています。日次でOpenAIを追う際は、ChatGPTの画面更新だけでなく、API/Realtime/音声/翻訳/Whisper/Agents/Codex/Statusを別軸で必ず確認しないと、今回のような「別ラインの大型更新」を落とします。
