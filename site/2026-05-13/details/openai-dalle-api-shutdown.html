DALL-E 2/3 APIの停止日。画像生成ワークフローはgpt-image系へ移行確認

30秒概要

OpenAI PlatformのDeprecationsでは、dall-e-2とdall-e-3のshutdown dateが2026年5月12日。APIでモデルIDを固定しているプロダクトは、gpt-image-1またはgpt-image-1-miniなどへの移行が済んでいないと当日障害になる。

本文要約

OpenAIのDeprecationsページは、2025年11月14日にDALL-E model snapshotsの非推奨化を通知し、2026年5月12日にdall-e-2とdall-e-3を停止すると明記しています。推奨置き換え先はgpt-image-1またはgpt-image-1-miniです。

影響を受けるのは、ChatGPT上で画像生成を使う一般ユーザーよりも、APIでdall-e-2やdall-e-3を直接指定しているアプリケーションです。生成、編集、バリエーションなどの処理でモデルIDをハードコードしている場合、5月12日以降にAPIエラーや機能停止につながります。

移行時は、単純にモデル名を置き換えるだけでなく、(1)プロンプトの出力傾向、(2)サイズ/品質/料金、(3)既存ユーザーが期待する画風や文字描画、(4)失敗時の再試行/フォールバック、(5)キャッシュ済みテンプレートのテストを確認する必要があります。画像生成はユーザー目線で品質差が見えやすいため、当日停止後に直すより、代表プロンプトでの比較を残しておくのが安全です。

運用チェック: APIログでdall-e-2/dall-e-3の呼び出しが残っていないか、モデル設定が環境変数・DB・管理画面・サンプルコードに分散していないかを確認。
