Release Notes

OpenAI、CodexのWindows向けComputer Use対応などを更新（ChatGPTのモデル整理も告知）

記事まとめ

OpenAIのリリースノートによると、CodexアプリはWindows上でComputer Useに対応し、対象ユーザーはWindowsアプリを見てクリックし入力する操作を依頼できるようになった。

同じ更新で、Codexの応答性や内蔵ブラウザの速度・安定性を改善したほか、Codex Profilesの導入も案内している。

またChatGPT側ではGPT-5.5 Instantの応答スタイルを調整し、o3は2026年8月26日、GPT-4.5は2026年6月27日にChatGPT内で順次サンセットするとしている（APIには適用しない）。

原文確認: ChatGPT Release Notes（2026/05/29, 05/28） / Codex Computer Use / Codex Remote Control
